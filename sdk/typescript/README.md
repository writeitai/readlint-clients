# readlint.com

TypeScript SDK, CLI and local MCP server for readlint.com. Requires Node.js 22+.

```sh
npm install readlint.com
npx readlint.com login
npx readlint.com list --limit 25 --offset 0 --json
```

Follow the maintained [TypeScript SDK](https://readlint.com/docs/typescript),
[CLI](https://readlint.com/docs/cli) and [MCP](https://readlint.com/docs/mcp)
guides for authentication, examples, expected results and recovery.
Python users can install `readlint` from PyPI or use `uvx readlint`.
